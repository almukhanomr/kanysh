# ADR-003: MCP server + local web viewer

Принято 2026-10-17 по уточнению пользователя. Заменяет UI/chat/voice/cloud scope ADR-002 и старого ТЗ.

Основной интерфейс — внешний MCP-клиент. Удалены собственные LLM/ASR adapters и SDK.
Научные операции доступны через MCP/CLI/REST. Gradio/Plotly находятся в extra `ui`;
UI показывает артефакты/ревизии/срезы, принимает файлы и открывает сохранённый Norne.

Viewer pages имеют стабильные URL, защищаются auth guard и выдаются через MCP только при
активном локальном просмотрщике. UI не требуется для вычислений и MCP resources.
Runpod изолирован в experimental/, не включается в wheel/sdist и полный MCP-профиль.
Тесты cloud имеют marker experimental и отдельную команду.
A-10 не обязателен: «заменено MCP-клиентами»; cloud-критерии также отделены от основной приёмки.
Научные границы и проверки сохраняются.
